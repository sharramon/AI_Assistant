Decisions taken (the recommended answers)

  • D3 (a): the sender is stamped on every command; sends and publishes strict; control commands only from "you" callers (and the core).   • D5 (a): ResetRequested, ShutdownRequested, AgentNotice become commands (the handler's own AgentNotice too).
  • D6 (a): the review becomes a listener that adds notes to a card; the core never starts a task.
  • D7 (a): the boundary tests (rules 1 to 3) come before any move.
