Summary

A highly modular personal AI assistant that serves as a long-term experimental platform. A small, stable core hosts an ever-changing set of independent modules (inputs, outputs, views, tools, background workers, and the AI orchestration itself) that can be added, replaced, or discarded with minimal changes elsewhere.

The style is a modular monolith using ports & adapters, dependency injection, and event-driven communication. Everything runs in one process. Changing code means a rebuild and restart; turning existing modules on and off happens while the app runs (runtime module control: built in the core; a control panel and asking the Talker come later). Loading new code without a restart and independent deployment are not goals.

The core runs on a PC today and will later move to a server, so it must not assume a local desktop: configuration, secrets, and data paths come from config files and environment variables, and user-facing interfaces are modules or remote clients. Headsets (Quest 3) and smartglasses are remote clients that connect over the network.
