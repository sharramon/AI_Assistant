html_viewer: the HTML viewer and its app

Purpose

View, edit, highlight and snip HTML files in tabs. html_viewer is the thin module; the viewer app (src/html_viewer) is its own program that doesn't import the assistant. On by default. Full design: HTML viewer.

Wrapper

Field Value
id html_viewer
provides IToolProvider
requires / optional none
permissions none declared

Interface
Tools viewer.open (open a file in a tab), viewer.highlight (open it and highlight a quoted part), viewer.tabs (open files and highlights): tools offered today
Handles InvokeTool for its tools (routed by the core)
Calls nothing
Publishes ViewerTabsChanged, ViewerClip (a snip, image copied into the launch's log folder)
Listens to AgentActivity: the Main Assistant's <<SHOW: ...>> lines, which it opens or highlights
To the app the viewer's local HTTP API (module → app) and its event stream (app → module)

Owns and launches

  • Launches the viewer app on the first show request, through CompanionApp (python -m html_viewer, port 8766), and quits it when the module stops. A viewer you started yourself is left running.
  • The app owns the tabs, highlights, snips, editing and saving, including writing text edits back to a generated page's Markdown source (generated folders).
