main_assistant: the worker agent

Purpose

A claude session with file tools that does the work handed to it by the Agent Hub. On by default. It is the coordinator ([modules.agent_hub] coordinator): other agents' milestones and ends, and each focus move, reach it at the end of its next message (working together). Design: agents, the Main Assistant on its own.

Wrapper

Field Value
id main_assistant
provides ITaskAgent (only the Hub calls it)
requires / optional none
permissions none declared; its file and shell access are its claude rules (config below)
needs none (Manifest.needs, from its module.toml): a core module, it needs no other module by id
packages none

Config

Defaults in module.toml in this module's folder, with their comments; [modules.main_assistant] in the app's config (your config/local.toml) only overrides them, key by key (a list such as write_dirs is replaced whole; how a module's config is built). config/default.toml has no section for it. The keys: workspace, tools, permission_mode, read_dirs, write_dirs, allowed_commands, fresh_sessions, max_handoffs, context_reminder, edit_note, permission_prompts, permission_timeout, transcript, model.
