main_assistant: the worker agent

Purpose

A claude session with file tools that does the work handed to it by the Agent Hub. On by default. It is the coordinator ([modules.agent_hub] coordinator): other agents' milestones and ends, and each focus move, reach it at the end of its next message (working together). Design: agents, the Main Assistant on its own.

Wrapper

Field Value
id main_assistant
provides ITaskAgent (only the Hub calls it)
requires / optional none
permissions none declared; its file and shell access are its claude rules (config below)
