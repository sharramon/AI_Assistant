temp_ui: the temporary two-pane page

Purpose

A local web page with the worker's activity on the left and the Talker conversation on the right, with the mic button, usage meters, permission cards and the Manual | Auto toggle. A throwaway stand-in until the UI handler is designed. On by default. Design: temp UI.

Config

Defaults in module.toml in this module's folder; your config/temp_ui.toml (top-level keys, gitignored; [modules.temp_ui] in config/local.toml still works, last) only overrides them, key by key (how a module's config is built). config/default.toml has no section for it. The keys: port (8765), window ("app"); host, window_profile and worker have their defaults in code.
