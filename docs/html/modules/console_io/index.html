console_io: terminal 1

Purpose

Terminal input and output: each line you type becomes an InputReceived, and the replies are printed. exit or quit shuts the app down. On by default.

Config

Defaults in module.toml in this module's folder; your config/console_io.toml (top-level keys, gitignored; [modules.console_io] in config/local.toml still works, last) only overrides them, key by key (how a module's config is built). config/default.toml has no section for it.
