agent_hub: who is doing what

Purpose

Holds the authoritative task state and routes work between the Talker and the task agents. Not an AI; launches nothing. On by default. Design: agents.

Wrapper

Field Value
id agent_hub
provides / requires nothing
optional ITaskAgent (every task agent; it never imports one)
permissions none

Interface
Tools none
Handles ListAgents, StartTask, GetTaskStatus, SendToTask, CancelTask, ReportTask, AnswerPermission, SetPermissionMode
Calls the agents' ITaskAgent methods
Publishes TaskUpdated
Listens to AgentActivity (kept per task as a view, not state)

Owns and launches

  • Task records: id, agent, text, TaskState, recent activity. State changes only from commands, so dropped events can't corrupt it.
