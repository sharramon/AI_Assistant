html_viewer: the HTML viewer and its app

Purpose

View, edit, highlight and snip HTML files in tabs. html_viewer is the thin module; the viewer app (src/html_viewer) is its own program that doesn't import the assistant. Off at launch, on when used: with start_on_use = true, the first page opened (a SHOW tag, the temp UI's Open in viewer button, any viewer.* call) turns it on through the core, even if you turned it off (start on use). modules.on / modules.off still work.
