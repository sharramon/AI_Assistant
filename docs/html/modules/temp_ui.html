temp_ui: the temporary two-pane page

Purpose

A local web page with the worker's activity on the left and the Talker conversation on the right, with the mic button, usage meters, permission cards and the Manual | Auto toggle. A throwaway stand-in until the UI handler is designed. On by default. Design: temp UI.

Interface
Tools none
Handles nothing
Calls ListModules, StartListening, StopListening, AnswerPermission, SetPermissionMode, InvokeTool viewer.open
Publishes InputReceived, ResetRequested, ViewerClipDropped
Listens to InputReceived, ResponseReady, TaskUpdated, AgentActivity, AgentStateChanged, PermissionModeChanged, SessionUsage, ViewerClip, VoiceState, VoiceTranscript, ModuleStateChanged

Owns and launches

  • A page server on 127.0.0.1:8765 (standard library): GET /events (Server-Sent Events), and POST /say, /permission, /permission-mode, /reset, /mic, /drop-snip, /open-in-viewer, /open-logs.
  • An Edge app window for the page (window = "app").
