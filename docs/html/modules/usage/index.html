usage: every agent's tokens since launch

Purpose

Keeps the usage tally of the whole app: every agent's tokens since the app started (tokens only: the claude tool's dollar estimate is at pay-as-you-go API prices, not what a subscription bills, so it isn't kept), with each agent's sub-agents and wrapped tools nested under it, and the Talker as its own row. It listens to SessionUsage from every sender and keeps one UsageLedger. Kept in memory only: nothing is written to disk, and the tally ends with the app. No time buckets, no history, no spend alerts. On at launch.
