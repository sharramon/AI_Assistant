talker: the agents' Talkers, one per agent tab

Purpose

Fast claude sessions that talk with you and hand work to the Agent Hub, one per agent tab (built 2026-11-05): each tab is a pair, its Talker and its agent (its partner), with its own chat. Tags in its replies become Hub commands and viewer tools. On by default. Design: agents, the Talker on its own.

id talker
provides / requires / optional optional IModuleDoor (the module door, from the Agent Hub)

Config

[modules.talker]: model (every tab's), turn_timeout, context_exchanges, context_warning, transcript (the main tab's name; a helper's gets -<agent>), restart_note, restart_timeout, door.
