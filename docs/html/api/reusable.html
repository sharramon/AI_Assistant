Voice service: voice_service

Its own app; never imports assistant. The protocol is shared with its Python clients; the rest is used inside the service and is where new engines and audio sources plug in.

Name Kind Purpose Where Used by
Voice service protocol models, functions The /ws/listen messages (with MicDropped, MicBack), ErrorCode, parse_client_message, parse_service_message, dump, ProtocolError voice_service/protocol.py voice_service server (server.py, session.py), voice_in client (the only part of the service it imports)
SttEngine, SttStream ABCs A speech engine (load, new_stream) and one session's stream (accept, partial, finish, optional set_prompt and cancel); load_engine picks one by name, once per role (live, final) voice_service/engines/__init__.py ZipformerEngine, WhisperEngine, FakeEngine, ListenSession (both engines; the voice-clean thread), transcribe; the Nemotron engine (step 7, planned)
Two-pass real check script The service in-process with the real models over WAVs fed at speech speed: CPU, partial lag, per-piece times, queue, wait after stop, text vs whole-recording whisper. Config overrides in memory only scripts/voice_two_pass_check.py the two-pass measurements (2026-11-03); the engine comparison (step 7, planned)
AudioSource ABC Where a session's PCM16 chunks come from: start(on_chunk, on_lost), stop() voice_service/audio.py MicSource, FakeSource, FileSource, ListenSession (through a factory: a fresh source to reopen a dropped mic); RemoteSource for /ws/audio (later)
FileSource class A 16 kHz mono WAV in chunks, read whole or fed like a mic; the one WAV reader voice_service/audio.py transcribe_file, FakeSource.from_wav, the engine comparison (step 7, planned)
transcribe, transcribe_file functions Text from an engine and a source (or a WAV path), with timings; no server, no mic voice_service/transcribe.py the transcribe command, the whisper measurements (2026-11-03), the engine comparison (step 7, planned)
FakeSource, FakeEngine classes Audio from a list or a WAV file; an engine that reveals a set text. Test and offline-check doubles voice_service/audio.py, voice_service/engines/fake.py tests/test_voice_service.py, tests/test_voice_in.py (the real service app on a local port), offline engine checks (FakeSource.from_wav); the engine comparison (step 7, planned)
