API Reference

Every public class and function, grouped by area. Check here before writing something new. If it already exists, reuse or extend it.

Each group links to a page with full signatures, parameters, return values, errors and examples. For how the pieces fit together, see the architecture overview.

Modules may use Modules, Messaging, Tools, and Infrastructure. Core host is internal to assistant.core; it's listed so nothing gets duplicated.
