API Reference

Every public class and function, grouped by area. Check here before writing something new. If it already exists, reuse or extend it.

Each group links to a page with full signatures, parameters, return values, errors and examples. For how the pieces fit together, see the architecture overview. For which module handles, sends, and listens to each type, see the module library.

Modules may use Modules, Messaging, Tools, Module control, Agents, Infrastructure, and App kit. Core host is internal to assistant.core; it's listed so nothing gets duplicated.

♻ Reusable marks a part built once and shared (principle 13). Its entry starts with Reusable · Used by: ….

  • Shared with the independent apps (app_kit): window, load_layered, local_path, CompanionApp
